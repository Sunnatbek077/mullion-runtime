# mullion-runtime

Published data for [Mullion](https://github.com/Sunnatbek077/Mullion), the macOS
app that wraps Windows games into standalone `.app` bundles.

Mullion only ever **reads** this repository, unauthenticated, over
`raw.githubusercontent.com`. Everything here is written by Mullion-Admin.

| File | What |
|---|---|
| `manifest.json` | The runtime component catalogue and the game compatibility list |
| `news.json` | The in-app news feed (absent until there is news; a 404 is an empty feed, not an error) |
| `checkout.html` | Paddle's default payment link — served by GitHub Pages, not read by the app |
